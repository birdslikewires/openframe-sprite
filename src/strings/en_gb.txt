# Sprite's on-screen text, in British English (en_gb).
#
# Each message is a line of its own:  key = text
#   - The key is how Sprite's code finds the message: leave it as it is.
#   - The text is everything after the first "=", less the spaces around it.
#   - \n starts a new line within a message; it's the only use of a backslash.
#   - %s, %d and the like are where Sprite puts something in (a name, a number). Keep each
#     one, in the same order: the build checks them against the code and stops if they
#     don't match. %% is a percent sign.
#   - Lines starting with # are notes, and Sprite ignores them.
#
# Another language goes in a file of its own beside this one (en_us.txt, say), with only the
# messages it changes; the rest come from here. Build with it as STRINGS_LANG=en_us.
#
# Dates and the clock (Mon 24 Nov, 2:15 pm) come from the system, not this file. So do the
# notes for updates, which come with each package.
